# SANZ GAME HUB
A futuristic PC game discovery site built with HTML5, CSS3 and vanilla JavaScript. No frameworks, no backend.

## Run
1. Unzip the folder.
2. Open `index.html` in a browser, or in VS Code right-click it and choose **Open with Live Server**.

## Replace the placeholders
- `assets/images/*.jpg` - the game cover images are generated placeholders. Swap in your own images with the same file names.
- `assets/video/gaming-trailer.mp4` - add a video. Until then the page shows a placeholder panel.
- `assets/audio/gaming-theme.mp3` - add a track for the audio player.

## Notes
- "VIEW GAME" buttons open official Steam, EA, Ubisoft or publisher pages in a new tab. No downloads are hosted.
- Check store links before submitting, since stores sometimes move pages.
